# Проверка надёжности — 2026-09-20

Область: исходники Android и часов, импорт, передача, сборка маршрута,
жизненный цикл, навигация, существующие тесты и документация.
Это проверка кода и доступных автоматических тестов, а не подтверждение
безотказной работы на реальных устройствах.

## Исправлено в 0.6.0 (курс)

| Риск | Изменение |
|---|---|
| На пешей скорости курс «мигал» между GPS и компасом → смещение карты | Гистерезис «в движении»; в движении только GPS-курс |
| Слабое качество GPS переводило курс на компас | GPS-курс допускается при POOR, если сэмплу ≤ 3 с |
| В начале маршрута вид шёл по «сырому» компасу | Поправка компаса сохраняется между запусками |
| Компас на запястье врёт стоя при поднятой руке | Меню Compass On/Off (Off — держать последний GPS-курс) |

Проверено unit-тестами часов в симуляторе (19/19); на устройстве — ещё нет.

## Исправлено в 0.4.1

| Риск | Изменение |
|---|---|
| После ошибки импорта отправлялся предыдущий маршрут | Сброс состояния перед чтением |
| Отменённая передача продолжала отправлять пакеты | Sender.cancel и отмена при смене маршрута/Activity/подключения |
| Импорт блокировал UI и не ограничивал память | Фоновая обработка, лимит текста и точек, защита от устаревших результатов |
| Неверные координаты попадали в расчёты | Проверка диапазонов, NaN/Infinity, структуры GeoJSON |
| XML мог содержать внешние сущности | Запрет DTD и объявлений entities до DOM-парсера |
| Пакеты часов принимались без проверки | Типы, размеры, состояния, индексы и координаты проверяются |
| Переполнение при сглаживании долготы | Обновление через разницу координат вместо суммы взвешенных абсолютных значений |
| SDK мог объявить готовность без подписки ACK | Готовность только после успешной регистрации; фильтрация событий старого SDK |

## Проверки

- Android: testSimDebugUnitTest, assembleHwDebug, lintHwDebug — успешно.
  30 тестов репозитория плюс 1 существующий локальный RealRouteMockGen: 31/31,
  без failures/errors. Локальный тест не включён в изменения версии.
- Garmin SDK 9.2.0: сборка для instinct3solar45mm и unit tests в симуляторе — 10/10.
- Новая логика Activity/SDK собрана и проверена lint; Android instrumentation-тестов
  для фонового импорта, поворота экрана и реального disconnect в проекте нет.
- На устройства ничего не устанавливалось; Gate 3 (сквозная передача) и Gate 4 не выполнены.
- Lint не даёт ошибок, но сообщает предупреждения о targetSdk 34, зависимости Gson,
  backup rules, ресурсах и строках интерфейса. Это не подтверждение актуальности зависимостей;
  отдельного аудита уязвимостей не выполнялось.

## Незакрытые риски и обязательные следующие проверки

| Приоритет | Риск / ограничение | Что требуется |
|---|---|---|
| Высокий | Нет идентификатора передачи; запоздалый ACK может совпасть с seq нового маршрута | Протокол v2 с transferId на обеих сторонах и тестами перестановки сообщений |
| Высокий | При потере GPS прежний hasFix не протухает; колбэк принимает позицию без проверки качества | Единая проверка качества/возраста фикса, подавление навигационных сигналов без свежего GPS, симуляция потери сигнала |
| Высокий | Прибытие определяется остатком вдоль маршрута без проверки удаления от линии; проверка выполняется до обработки паузы | Проверить и исправить прибытие вне маршрута и во время паузы с регрессионными сценариями |
| Высокий | Все манёвры передаются одним M, предел размера CIQ на железе не измерен | Измерить максимальный пакет; для больших списков согласовать чанкинг в v2 |
| Средний | Маршрут и состояние передачи не сохраняются при смерти процесса/перезапуске часов | Спроектировать восстановление; проверить поворот экрана, сворачивание, убийство процесса |
| Средний | N(seq) не возвращает Sender к недостающему чанку | Сейчас повтор вручную с H; проверить рестарт часов посреди передачи |
| Средний | Поддержка многосегментных GPX объединяет сегменты; локальная проекция не рассчитана на переход ±180° | Определить допустимую географию и поведение разрывов трека |
| Средний | Фоновое чтение от content provider может задерживаться; очередь импортов не ограничена | Стресс-тест быстрых повторных Share и зависшего источника |
| Средний | Нет непрерывной CI-проверки Android/часов и согласованности версий | Добавить воспроизводимую CI-сборку с доступными SDK, без приватного ключа в репозитории |

прохождения сквозных и аппаратных проверок. Журнал версий: CHANGELOG.md;
