# История версий

## 0.6.0 — 2026-10-11, подготовлена, не выпущена

Android versionCode: 10; часы: v0.6.0; протокол: v2 (без изменения схемы).
Код телефонного приложения не менялся — для проверки достаточно обновить часы.

- Курс heading-up: состояние «в движении» с гистерезисом (вход от 1.0 м/с, выход ниже 0.5 м/с
  дольше 3 с). Раньше на пешей скорости курс «мигал» между GPS и компасом, и карта получала
  устойчивое смещение от размаха руки, хотя прогресс по маршруту считался верно.
- В движении курс только по GPS; кратковременный провал GPS — курс удерживается, компас
  не подмешивается.
- Курс GPS используется уже при качестве POOR, если сэмплу не больше 3 с: курс GNSS по
  допплеру надёжен и при посредственной позиции. Прогресс по маршруту по-прежнему требует GOOD.
- Поправка компаса, выученная в движении, сохраняется между запусками — в начале маршрута вид
  не опирается на «сырой» компас.
- Меню навигации: Compass On/Off. Off — стоя карта держит последний курс GPS (не врёт, но не
  вращается на месте).
- Стартовый экран: при запуске показывается ожидание трека «Waiting for route (.gpx)»; прошлый
  маршрут — по START/MENU («START: last route»). BACK на обзоре возвращает к ожиданию,
  на ожидании — выход. После завершения навигации — снова ожидание.
- Логика курса вынесена в NavState.updateHeading; часы: 19 unit-тестов в симуляторе (+4).

## 0.5.2 — 2026-10-10

Android versionCode: 9; часы: v0.5.2; протокол: v2 (без изменения схемы).
Объединяет изменения распространения/UI (ранее готовились как 0.5.1).

- Android собирается в release со своим стабильным ключом (не debug) — меньше недоверия при
  сайдлоаде; ключ/пароли вне git (`keystore.properties`).
- Экран ожидания на часах показывает ожидаемый формат «from phone (.gpx)».
- Метка версии выводится вертикальным столбиком по левому краю — не перекрывается ни
  субэкраном справа-сверху, ни линией маршрута по центру.
- Добавлена лицензия MIT; в README — установка у других (self-signed, SHA-256, разовый prompt).

## 0.5.0 — 2026-09-20, подготовлена, не выпущена

Android versionCode: 7; часы: v0.5.0; протокол: v2 (схема изменена — обе стороны обновлять вместе).

- Протокол v2: у каждого пакета идентификатор передачи `id`; манёвры разбиваются на чанки
  (`mc`) с последовательностью nc..nc+mc-1; лимит имени маршрута 60 символов; коды отказа N —
  invalid/restart/version/storage/busy.
- Маршрут сохраняется на часах (Application.Storage) и восстанавливается при запуске —
  переживает перезапуск приложения.
- Во время активной навигации новый входящий маршрут отклоняется ответом N «busy».
- Идемпотентная обработка повторных H/E и дублей чанков (переотправка ACK); чанк
  валидируется целиком до изменения буфера сборки.
- Устойчивый импорт на телефоне вне UI-потока; генерация 32-hex идентификатора передачи;
  sim-флейвор получает INTERNET только для симулятора (на железе разрешение не запрашивается).
- Синтетический публичный DemoRoute заменил приватный мок в демо-режиме.
- Build-time контракт (verifyContract): перед сборкой сверяет версии, константы протокола,
  UUID и отсутствие нелатинских строковых литералов в исходниках.

## 0.4.2 — 2026-09-20, подготовлена, не выпущена

Android versionCode: 6; часы: v0.4.2; протокол: v1.

- GPS принимается только с качеством GOOD и выше и возрастом не более 10 секунд.
- Повтор одного GPS-фикса при опросе больше не запускает сглаживание заново.
- Без свежего GPS и на паузе не обновляется прогресс, нет сигналов поворота,
  схода с маршрута и определения прибытия; карта остаётся видна с Waiting for GPS.
- Прибытие требует близости к конечной точке и прохождения заключительной части маршрута.
- MENU на обычной сборке открывает меню, а не включает искусственное движение.
- Добавлены тесты потери GPS, повторов фикса, паузы и финиша вне линии.

## 0.4.1 — 2026-09-20, подготовлена, не выпущена

Android versionCode: 5; часы: v0.4.1; протокол: v1 (без изменения схемы).

- Отмена Sender останавливает обработку поздних ACK/NACK и таймаутов.
- Пустая передача завершается без падения; таймер включается до отправки пакета.
- Замена маршрута, переподключение и уничтожение Activity отменяют передачу.
- Ошибка импорта больше не оставляет предыдущий маршрут доступным для автоотправки.
- Импорт выполняется вне UI-потока; результаты старого импорта игнорируются.
- Ограничения импорта: 2 000 000 символов и 10 000 исходных точек.
- GPX запрещает DTD/entities; GPX/GeoJSON проверяют конечность и диапазон координат.
- Ненавигируемый маршрут из одной точки или одинаковых точек отклоняется.
- Потеря связи отменяет передачу; устаревшие события остановленного SDK фильтруются.
- Часы проверяют входящие пакеты, границы буферов и индексы манёвров.
- Исправлено переполнение долготы при сглаживании GPS на часах.
- Исправлено описание фактической обработки M, N и несовместимой версии протокола.
- Добавлены регрессионные тесты Android и часов. Результаты и ограничения — RELIABILITY.md.
